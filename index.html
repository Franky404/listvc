Pengaturan dokumen

Sesuaikan kertas dan tampilan cetak

⚙️

👋 Selamat datang! Cara menggunakan

  1. Atur ukuran dan tampilan kertas pada bagian Pengaturan dokumen.
  2. Edit nama voucher, lalu ubah atau tambah daftar paket di bagian Daftar Voucher.
  3. Lihat hasilnya di Pratinjau cetak. Perubahan akan tampil otomatis.
  4. Jika sudah sesuai, pilih Cetak / Simpan PDF untuk mencetak atau menyimpan PDF. Pilih Unduh Foto untuk menyimpan hasil sebagai gambar.

Tata letak kertas

Pilih ukuran kertas yang akan digunakan saat mencetak.
Potret memanjang ke atas; lanskap melebar ke samping.
Mengatur besar-kecilnya tulisan pada daftar voucher.
Mengatur ruang tepi kertas, terutama bagian atas dan kiri.
Mengatur jarak antarbaris agar daftar lebih rapat atau renggang.

Cetak / Simpan PDF: buka menu cetak perangkat, lalu pilih printer atau opsi “Simpan sebagai PDF”. Unduh Foto: simpan pratinjau sebagai gambar PNG.

Pilih ukuran kertas yang sama di dialog cetak dan di printer. Untuk memastikan satu halaman, website akan memadatkan jarak baris secara otomatis sesuai jumlah data.

Daftar Voucher

Ubah nama voucher dan daftar paket sesuai kebutuhan

Tips: ketuk kolom nama untuk mengganti nama voucher. Ketuk kolom paket untuk mengubah isinya. Tombol × menghapus satu paket, sedangkan tombol Hapus menghapus seluruh kategori voucher.

Tambah Voucher membuat kategori baru. Paket terakhir menambah satu baris paket pada kategori paling bawah. Reset contoh mengembalikan daftar awal dan mengganti semua perubahan.

💾 Data tersimpan otomatis di browser pada perangkat ini. Data tidak otomatis tersinkron ke HP atau browser lain. Jangan hapus data browser jika ingin mempertahankan daftar yang sudah dibuat.
